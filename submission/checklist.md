# Submission Checklist

## Repository

- Public repository is created
- `LICENSE` is present
- `README.md` explains architecture and setup

## Agent Builder

- Managed agent is created
- System prompt is loaded
- Grounding files are uploaded
- GitLab MCP integration is connected
- Hosted endpoint or web interface is reachable

## Security

- GitLab credentials are stored in Secret Manager
- No secrets are committed in the repository

## Demo

- One reproducible failed pipeline is selected
- Demo stays within three minutes
- GitLab MCP tool use is visible in the walkthrough

## Devpost

- Hosted project URL is ready
- Public repository URL is ready
- Demo video URL is ready
- Submission copy is pasted and aligned to the GitLab track
